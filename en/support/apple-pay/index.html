Apple Pay + OnlyMoney

Automatic Apple Pay expenses

Pay with your iPhone. Let a personal automation save the expense in OnlyMoney, ready for you to review later.

Before you begin

Use an iPhone with Apple Pay and an OnlyMoney version that includes the Record Apple Pay Expense action. Complete setup in OnlyMoney and create an active account in the same currency as your purchases. Open OnlyMoney once after installation or updating.

Set up the automation

  1. Open Shortcuts on your iPhone, select Automation, then tap + to create a personal automation.
  2. Choose Wallet or Transaction (the label depends on iOS). Under When I tap, select the card you want to track. Leave merchant and category filters unrestricted to capture all eligible taps.
  3. Choose Run Immediately, then Next. If your iOS version uses Ask Before Running, turn it off. During setup, keep Notify When Run enabled so you can check the automation.
  4. Choose New Blank Automation or create a blank shortcut. Add the OnlyMoney action Record Apple Pay Expense.
  5. For Account, select the OnlyMoney account corresponding to that card. For Amount, insert Shortcut Input or Transaction, tap the variable again, and select Amount. Keep the payment currency attached to the amount; if Shortcuts asks for a currency, choose the actual payment currency.
  6. For Merchant, insert the same transaction input and select Merchant. This field is optional. Save the automation. For another card or account, create a separate automation with its own account selection.

After your first payment

Make one small eligible purchase with your iPhone and inspect the automation notification or run history. Open OnlyMoney and check the account, amount, currency, date, and merchant note. The expense appears under Other Expenses. Open the transaction, select Edit, and change its category whenever you want. Once verified, you may turn off Notify When Run.

What to expect

  • This is an optional Wallet tap automation, not a bank connection or a complete statement import. Online payments, subscriptions, refunds, cash, and transfers are not covered by this guide. Apple Watch payments are not guaranteed to trigger the iPhone automation.
  • OnlyMoney receives the supplied amount, currency, selected account, and optional merchant. It stores the expense locally using today’s device-local date and keeps the merchant in the note. It does not receive your card number or bank credentials through this action.
  • The payment currency must match the selected account. A mismatch stops the action without saving an expense. For a foreign-currency account, OnlyMoney snapshots the base-currency equivalent using its stored offline rate; this is not the bank’s final conversion rate.
  • A Wallet tap is not proof of settlement. Check declined payments, changed amounts, and refunds against your bank. Correct or delete an inaccurate expense in OnlyMoney.
  • Each successful action run creates one expense. Do not install overlapping automations for the same card or manually rerun a successful payment: this can create duplicates.

If an expense is missing

Check the selected card, merchant/category filters, immediate-run setting, and automation history. Confirm that the amount has the correct currency and the account is active. Open OnlyMoney after updating. After restoring a backup from another dataset, select the account again. A legacy archived Other Expenses category must be restored first. If an account-to-base rate is unavailable, resolve that in OnlyMoney before retrying. Check whether the expense already exists before rerunning.

Privacy

The automation passes payment details on your device; OnlyMoney does not upload them to the developer. Opening this online guide uses your browser and GitHub Pages hosting.
